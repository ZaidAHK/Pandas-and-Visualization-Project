# Retail Inventory & Sales Analysis

A retail inventory and sales analysis project using Pandas, Matplotlib, and Seaborn with `retail_inventory.csv`.

## What it covers
- Data inspection and validation
- Product and inventory analysis
- Stock/reorder analysis
- Product sales and revenue
- Supplier sell-through performance
- Supplier sales share
- Monthly inventory trends
- August 2025 sales analysis
- Category and store performance
- Pivot tables and frequency analysis
- Bar, line, and pie visualizations

## Libraries
- pandas
- matplotlib
- seaborn

## Files
- `Retail_inventory_project.ipynb`
- `retail_inventory.csv`
